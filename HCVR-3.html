HCVR-3 Series - Conventional Fire Alarm Releasing System

LEVEL 2 暫停功能

功能 端子 代碼 描述
測試ZONE ZONE 1 t1 選擇代碼 t1, t2 或 t3 將ZONE 1, 2 或 3 置於測試模式。測試模式下的ZONE在操作後 3 秒自動重置。當ZONE 1, 2, 或 3 處於測試模式時，測試模式開啟和ZONE故障/測試中/停用指示燈會亮起。
ZONE 2 t2
ZONE 3 t3
停用ZONE ZONE 1 d1 選擇代碼 d1, d2 或 d3 停用ZONE 1, 2 或 3。停用ZONE不會在火災控制面板上提供火災或故障指示。當ZONE 1, 2, 或 3 被停用時，盤面停用和ZONE故障/測試中/停用指示燈會亮起。
ZONE 2 d2
ZONE 3 d3
停用 NAC 1 NAC1 db 選擇代碼 db 停用 NAC1 輸出。當 NAC1 被停用時，盤面停用和 NAC 故障/停用指示燈會亮起。
停用第一階段繼電器 1ST STAGE dP 選擇代碼 dP 停用第一階段繼電器。當第一階段繼電器被停用時，盤面停用指示燈會亮起。
停用第二階段繼電器 2ND STAGE dA 選擇代碼 dA 停用第二階段繼電器。當第二階段繼電器被停用時，盤面停用指示燈會亮起。
停用排氣扇繼電器 EXTRACT dc 選擇代碼 dc 停用排氣扇繼電器。排氣扇停用指示燈停止亮起，盤面停用指示燈會亮起。
停用手動釋放 MAN. RELEASE dt 選擇代碼 dt 停用手動釋放輸入。當手動釋放輸入被停用時，盤面停用指示燈會亮起。
停用滅火劑釋放 EXTING. dE 選擇代碼 dE 停用預釋放計時器和滅火劑放射。當滅火劑釋放被停用時，滅火劑放射故障狀況會被忽略。
啟動延遲 Ad 選擇代碼 Ad 以啟動訪問級別 3 選項 C00 至 C09 的延遲。
關閉排氣扇接觸器 EXTRACT Ac 選擇代碼 Ac 並按下 HCVR-3 釋放火災控制面板上的 Enter 按鈕，以關閉排氣扇終端的常開接觸器。再次按下 Enter 按鈕會打開接觸器。

HCVR-3 釋放式火災控制面板 - 故障排除

當安裝或配置後出現衝突時，對HCVR-3釋放式火災控制面板進行故障排除。監控火災控制面板下方面板的指示燈以確定故障狀況的原因。打開HCVR-3釋放式火災控制面板的櫃門後即可看到下方面板的指示燈。

下圖展示了HCVR-3釋放式火災控制面板的下方面板指示燈：

Indicator Description
Mains Fail 115V/230V交流電源不存在，系統正在使用備用電池運行。如果沒有停電，請檢查主端子排的保險絲是否因電源丟失而熔斷。
Batt Fail 備用電池已斷開或火災控制面板的充電電路故障。檢查兩塊電池是否已連接並相互連接。測試電池。斷開電池並確保在電池充電導線上可以測量到28伏電壓。
CPU Tribl 中央處理單元未能執行代碼並已被系統Watchdog重新啟動。必須按下Watchdog重置開關以清除CPU故障狀況。按下Watchdog重置。如果系統未恢復正常，則面板可能已損壞，需要更換電路板。
Aux 24V Tribl Aux 24V和R0V端子提供500毫安、24V直流電源供火災報警輔助設備使用。此LED指示保護R0V輸出的保險絲已動作且此輸出的額定值已超出。保險絲為自恢復類型，當故障狀況消除後供電將恢復。
Batt Low 當系統使用電池運行且電池電壓在21.5V至20.5V（最低電池電壓）之間時亮起。
Comms Tribl 與遠程指示器或輔助板的通信已丟失。檢查所有遠程指示器和輔助板的通信故障以確定問題來源。通信故障LED將伴隨前面板的故障LED，指示火災控制面板釋放劑部分的常見故障狀況。
Earth Tribl 系統部分線路已接地。移除所有系統線路並逐一重新連接電纜，直到接地故障再次出現。這將指示哪條電纜存在接地故障。
Sys Fuse Trbl 電源供應的額定功率已超出且系統保險絲已動作。移除並檢查所有負載，然後逐一重新連接，直到過載電路觸發保險絲以識別故障電路。
S1, S2 and S3 Trbl NAC輸出存在短路或開路。移除接線並重新連接終端電阻。檢查NAC電路接線。S3 LED將伴隨前面板的故障LED，指示火災控制面板釋放劑部分的常見故障狀況。
Exting Trbl 釋放劑輸出存在短路或開路。移除接線並重新連接終端電阻。檢查釋放劑電路接線。Exting故障LED將伴隨前面板的故障LED，指示火災控制面板釋放劑部分的常見故障狀況。
Abort Trbl 緊急停止開關輸入存在短路或開路。移除接線並重新連接終端電阻。檢查中止電路接線。Abort故障LED將伴隨前面板的故障LED，指示火災控制面板釋放劑部分的常見故障狀況。
Manual Release Trbl 手動釋放開關輸入存在短路或開路。移除接線並重新連接終端電阻。檢查手動釋放電路接線。手動釋放故障LED將伴隨前面板的故障LED，指示火災控制面板釋放劑部分的常見故障狀況。
Mode Trbl 模式開關輸入存在短路或開路。移除接線並重新連接終端電阻。檢查模式電路接線。Mode故障LED將伴隨前面板的故障LED，指示火災控制面板釋放劑部分的常見故障狀況。
Release Trbl 釋放壓力開關輸入存在短路或開路。移除接線並重新連接終端電阻。檢查釋放壓力開關電路接線。Released故障LED將伴隨前面板的故障LED，指示火災控制面板釋放劑部分的常見故障狀況。
Low Pres Trbl 低壓開關輸入存在短路或開路。移除接線並重新連接終端電阻。檢查低壓開關電路接線。低壓故障LED將伴隨前面板的故障LED，指示控制面板釋放劑部分的常見故障狀況。
Tell Tale 面板安裝或遠程手動釋放按鈕已被按下。只能通過按下處理器重置和Watchdog重置或關閉火災控制面板電源來重置。
